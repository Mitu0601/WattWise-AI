# WattWise AI – EcoBudget Chatbot

## Overview
WattWise AI is an intelligent conversational agent developed as part of the Kaggle & Google AI Agents Intensive Capstone Project. The chatbot helps users analyze household electricity usage and make eco-friendly, cost-efficient energy decisions.

## Purpose
The goal of this project is to apply AI agent concepts to a real-world sustainability problem by assisting users in reducing energy consumption and environmental impact.

## Features
- Conversational AI interface for electricity usage analysis
- Monthly cost prediction based on usage patterns
- Eco-friendly energy-saving recommendations
- Budget-aware optimization suggestions

## Tech Stack
- Python  
- AI Agent framework (Kaggle AI Agents Intensive)  
- Natural Language Processing (LLMs)  
- pandas, NumPy  

## How to Run
1. Clone the repository  
2. Install dependencies using `pip install -r requirements.txt`  
3. Run the main agent script  
4. Interact with the chatbot through the terminal or UI  

## Impact
WattWise AI demonstrates how autonomous AI agents can support sustainable living by promoting responsible energy usage and informed decision-making.
